# NexusField - Field Operations & Inventory Companion App

[![Flutter](https://img.shields.io/badge/Flutter-3.47.5-blue.svg)](https://flutter.dev/)
[![Dart](https://img.shields.io/badge/Dart-3.0%2B-informational.svg)](https://dart.dev/)
[![Platform](https://img.shields.io/badge/Platform-Cross--Platform%20%7C%20Web%20%7C%20Mobile-orange.svg)](https://flutter.dev/)

A modern, cross-platform mobile application designed for field agents and inventory managers to monitor remote hardware nodes, track telemetry tasks, and manage operational workflows efficiently on the go.

---

## 🚀 Key Features
* **Interactive Operations Dashboard:** Real-time statistics cards tracking active sensor nodes and pending field duties.
* **Telemetry & Task Queue:** Dynamic priority-based list view highlighting critical operational jobs, firmware updates, and maintenance schedules.
* **Adaptive Navigation:** Clean Material 3 UI layout with a bottom navigation bar and stateful tab management.
* **Cross-Platform Architecture:** Built using Flutter and Dart, allowing seamless deployment across mobile devices and desktop/web environments.

---

## 🛠️ Tech Stack
* **Framework:** Flutter (Material 3 UI System)
* **Language:** Dart
* **State Management:** Stateful Widget Architecture
* **Target Platforms:** Android, iOS, Web (Chrome)
